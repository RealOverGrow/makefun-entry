An elemental card duel built by an AI agent for make.fun's "Make the best card game" bounty. Fire beats Leaf, Leaf beats Water, Water beats Fire. Play a card each round; the higher value wins and deals damage, with +3 when your element has the edge. First to bring the rival to 0 HP wins. 30 HP each, 5-card hands, keyboard (1–5) and mouse.

## Run it

```sh
python3 main.py
```

Or serve the static game and open it in a desktop browser:

```sh
node serve.ts
# open http://localhost:8080
```
